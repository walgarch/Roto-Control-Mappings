# Archived Traveler mappings

These files are preserved unchanged for provenance and comparison. They are cataloged and structurally validated but are not recommended for new installations.

## `traveler-native-v1.json`

The earlier 64-knob/10-button native mapping predates the owner's screenshot-driven corrections. It includes superseded control choices and waveform assumptions. Use the canonical mapping at [`../plugin/traveler.json`](../plugin/traveler.json) instead.

## `traveler-trial-pre-rc.json`

The final experimental trial immediately preceding promotion. It is byte-identical to the canonical mapping and is retained only to preserve the named historical artifact requested during development.

No archived mapping should be edited to match current conventions; any future correction belongs in a new version or the canonical mapping with an explicit semantic review.
